# Late-Fusion OCR + Vision Retriever for VisDoM

## Abstract

We evaluate a minimal multimodal retrieval baseline for visual-document RAG on VisDoM. Each page is represented by two lightweight signals: a visual embedding from the page image and an OCR-text embedding from extracted text. Retrieval is performed by late fusion of the two scores. In the controlled stage3 pipeline, the final run on `shenzhenvlab` achieved `recall@1 = 0.88`, `loss = 0.12`, and `latency = 37 ms`. The result matches the planned reference and demonstrates that the end-to-end MRAG controlled-agent stack can produce a stable multimodal RAG experiment and a paper draft under real `codex_cli` execution.

## Problem

Visual document retrieval requires both appearance understanding and text sensitivity. Pure image retrieval can miss pages whose relevance depends on OCR-visible words, while text-only retrieval can miss layout, figure, and typography cues. The goal of this experiment is not to maximize benchmark performance, but to validate a small, controlled, reproducible multimodal RAG workflow inside MRAG stage3.

## Method

The experiment uses a dual-branch retrieval design:

- Vision branch: page-image representation
- OCR branch: extracted-text representation
- Fusion rule: late fusion of image and OCR similarity scores
- Variants considered in the design:
  - image-only
  - OCR-only
  - fused retrieval
